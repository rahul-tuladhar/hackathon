## Design Context

### Users
Job seekers tailoring a long source résumé to a specific role. The current real-world workflow uses Rahul Tuladhar's résumé, a target job, and a one-page ATS-friendly PDF.

### Brand Personality
Focused, credible, and calm, with a playful edge. The interface should help users feel in control of the evidence and confident in the final document.

### Aesthetic Direction
Use the existing job-board language: light-first zinc neutrals, white navigation surfaces, blue interaction accents, Geist typography, and matching dark-mode variants. Keep the workspace editorial and easy to scan. The attached Codex app references guide the account menu and broad settings dialog structure; add a little warmth while keeping the settings practical and compact.

### Design Principles
- Keep global navigation distinct from section navigation inside a résumé workspace.
- Make role, employer, source evidence, and export state easy to scan.
- Keep résumé claims tied to source material; use original source points to fill thin tailored output.
- Preserve a compact, single-column hierarchy in the one-page PDF.
- Adapt the workspace navigation for narrow screens without hiding core destinations.
- Keep account actions discoverable from a persistent profile button, with settings available on every route.
- Use familiar controls with clear labels and immediate feedback.
